# C Programming Journey

This repository contains my C programming practice as I learn C step by step.

## Topics Covered

### Day 1 - Introduction
- Basic C program structure
- Variables
- Data types
- Input and output
- Basic programs

### Day 2 - Bitwise Operators
- AND (`&`)
- OR (`|`)
- XOR (`^`)
- NOT (`~`)
- Left shift (`<<`)
- Right shift (`>>`)

### Day 3 - Pointers
- Pointer basics
- Address operator (`&`)
- Dereference operator (`*`)
- Pointers and arrays
- Passing arrays to functions
- Searching arrays using pointers
- Counting elements
- Reversing arrays
- Pointer arithmetic
- Pointer movement using `p++` and `p--`
- Pointer comparison
- Pointer to pointer (`**pp`)

## Goal

My goal is to build a strong foundation in C programming and gradually move toward Embedded Systems programming.
